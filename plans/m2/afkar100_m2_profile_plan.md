# Afkar100 M2 Plan: Profile Page

**Source:** `plans/afkar100_project_plan.md`  
**Scope:** Milestone 2, Profile page only  
**Milestone Goal:** The user can review account information, activity, follows, and notifications from one place.

---

## Milestone

Deliver a profile page with account information and tabbed personal activity views.

---

## Tasks

- [ ] Display user profile information with edit capability
- [ ] Add `My Ideas` tab with status per idea: pending, approved, rejected, winner
- [ ] Add `Ideas I Voted For` tab
- [ ] Add `Ideas I Follow` tab
- [ ] Add `People I Follow` tab
- [ ] Add `Messages and In-App Notifications` tab
- [ ] Mark notifications as read when clicked

---

## Deliverables

- [ ] Profile page shell
- [ ] Tabbed activity sections
- [ ] Editable profile data area
- [ ] Read-state handling for notifications

---

## Done Criteria

- [ ] The profile page renders user data correctly
- [ ] Each tab shows the correct user-related records
- [ ] Idea statuses are visible in `My Ideas`
- [ ] Notification click actions update read state
