# Afkar100 M2 Plan: Archive Page

**Source:** `plans/afkar100_project_plan.md`  
**Scope:** Milestone 2, Archive page only  
**Milestone Goal:** The user can browse all approved ideas through filtering, search, and sorting.

---

## Milestone

Deliver an archive page for all approved ideas, including winners and non-winners.

---

## Tasks

- [ ] Display all approved ideas, both winning and non-winning
- [ ] Add filters: category, day, month, and status
- [ ] Add text search in title and description
- [ ] Add sorting: newest first and most voted
- [ ] Add pagination or infinite scroll
- [ ] Add a `Winner` badge on winning ideas

---

## Deliverables

- [ ] Archive page route and rendering
- [ ] Filter controls
- [ ] Search and sorting controls
- [ ] Pagination or infinite scroll
- [ ] Winner badge presentation

---

## Done Criteria

- [ ] Archive content loads correctly
- [ ] Filters reduce results correctly
- [ ] Search works against title and description
- [ ] Sorting changes result order correctly
- [ ] Winning ideas are clearly labeled
