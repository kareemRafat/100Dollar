# Afkar100 M3 Plan: Platform Statistics

**Source:** `plans/afkar100_project_plan.md`  
**Scope:** Milestone 3, Platform Statistics only  
**Milestone Goal:** The admin can monitor platform activity through summary metrics and charts.

---

## Milestone

Deliver a statistics area showing operational and growth indicators for the platform.

---

## Tasks

- [ ] Show daily and weekly submitted idea counts in a chart
- [ ] Show total votes over time in a chart
- [ ] Show weekly new user counts
- [ ] Show top 5 most shared ideas
- [ ] Show idea distribution by country

---

## Deliverables

- [ ] Ideas activity chart
- [ ] Votes-over-time chart
- [ ] Weekly new users metric
- [ ] Top shared ideas section
- [ ] Country distribution section

---

## Done Criteria

- [ ] Admin can view idea activity trends
- [ ] Admin can view vote trends
- [ ] Admin can inspect weekly user growth
- [ ] The top 5 shared ideas are visible
- [ ] Country-based distribution is visible
