# Afkar100 M3 Plan: Platform Statistics

**Source:** `plans/afkar100_project_plan.md`  
**Scope:** Milestone 3, Platform Statistics only  
**Milestone Goal:** The admin can monitor platform activity through summary metrics and charts.

---

## Milestone

Deliver a statistics area showing operational and growth indicators for the platform.

---

## Tasks

- [x] Show daily and weekly submitted idea counts in a chart
- [x] Show total votes over time in a chart
- [x] Show weekly new user counts
- [x] Show top 5 most shared ideas (Note: currently uses top voted ideas as proxy)
- [x] Show idea distribution by country

---

## Deliverables

- [x] Ideas activity chart
- [x] Votes-over-time chart
- [x] Weekly new users metric
- [x] Top shared ideas section
- [x] Country distribution section

---

## Done Criteria

- [x] Admin can view idea activity trends
- [x] Admin can view vote trends
- [x] Admin can inspect weekly user growth
- [x] The top 5 shared ideas are visible
- [x] Country-based distribution is visible
