# Afkar100 M3 Plan: Admin Panel

**Source:** `plans/afkar100_project_plan.md`  
**Scope:** Milestone 3, Admin Panel only  
**Milestone Goal:** The admin can access and navigate a dedicated control panel.

---

## Milestone

Deliver the base admin panel shell with protected access, dashboard metrics, and navigation.

---

## Tasks

- [ ] Apply `AdminOnly` middleware to all `/admin` routes
- [ ] Build the main dashboard with 4 metric cards: ideas, votes, users, sponsors
- [ ] Build sidebar navigation with icons

---

## Deliverables

- [ ] Protected `/admin` route group
- [ ] Admin dashboard page
- [ ] Sidebar navigation layout

---

## Done Criteria

- [ ] Non-admin users cannot access `/admin`
- [ ] The dashboard loads successfully for admins
- [ ] The four metric cards are visible
- [ ] Sidebar navigation works across admin pages
