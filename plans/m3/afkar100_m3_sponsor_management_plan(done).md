# Afkar100 M3 Plan: Sponsor Management

**Source:** `plans/afkar100_project_plan.md`  
**Scope:** Milestone 3, Sponsor Management only  
**Milestone Goal:** The admin can manage sponsor records, review join requests, and track prize responsibility.

---

## Milestone

Deliver sponsor management tools for creating, editing, activating, and tracking sponsor-related obligations, plus a workflow for reviewing incoming sponsorship requests.

---

## Tasks

### Sponsor Management
- [x] Add a new sponsor with name, logo, assigned day, and contract dates
- [x] Edit an existing sponsor
- [x] Activate or deactivate a sponsor
- [x] Track weekly prize payment status for each sponsor

### Sponsorship Requests Review
- [x] List all sponsorship requests with status filtering
- [x] View sponsorship request details
- [x] Approve request (transition to sponsor creation)
- [x] Reject request

---

## Deliverables

- [x] Sponsor list and management view
- [x] Sponsor create/edit forms
- [x] Sponsorship requests list view
- [x] Sponsorship request detail/review modal/page
- [x] Sponsor payment tracking view

---

## Done Criteria

- [x] Admin can create a sponsor record manually
- [x] Admin can edit sponsor details
- [x] Admin can activate or deactivate a sponsor
- [x] Admin can view list of sponsorship requests
- [x] Admin can approve a request, creating a sponsor
- [x] Admin can reject a request
- [x] Prize payment status is visible per sponsor
