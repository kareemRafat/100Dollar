# ملخص نظام التنبيهات في "أفكار بـ 100 دولار"

## تنبيهات الإدارة (Admin)
تُرسل إلى جميع المستخدمين الذين يمتلكون رتبة "مدير" (admin).

| التنبيه | سبب الإرسال | داخل التطبيق | البريد الإلكتروني |
| :--- | :--- | :---: | :---: |
| **فكرة جديدة قيد الانتظار** | عند قيام مستخدم بتقديم فكرة مشروع جديدة. | ✅ | ❌ |
| **رسالة تواصل جديدة** | عند إرسال زائر لرسالة عبر نموذج "اتصل بنا". | ✅ | ✅ |

---

## تنبيهات المستخدمين (User)
تُرسل للمستخدمين العاديين بناءً على نشاطاتهم وتفاعل الآخرين مع أفكارهم.

| التنبيه | سبب الإرسال | داخل التطبيق | البريد الإلكتروني |
| :--- | :--- | :---: | :---: |
| **الموافقة على الفكرة** | عند قيام المدير بالموافقة على فكرة معلقة. | ✅ | ✅ |
| **رفض الفكرة** | عند قيام المدير برفض الفكرة (يتضمن سبب الرفض). | ✅ | ✅ |
| **إعلان الفائز** | عند اختيار الفكرة كفائزة بجائزة الـ 100 دولار. | ✅ | ✅ |
| **تعليق جديد** | عند قيام شخص بالتعليق على فكرة المستخدم. | ✅ | ❌ |
| **متابع جديد** | عند قيام مستخدم آخر بمتابعة الملف الشخصي. | ✅ | ❌ |

---

## ملاحظات تقنية
- **إرسال البريد:** يتم عبر "الطابور" (Queued Jobs) لضمان سرعة أداء الموقع.
- **داخل التطبيق:** تُخزن في قاعدة البيانات وتُعالج ديناميكياً لدعم اللغة والاتجاه (RTL).
- **لوحة التحكم (Admin):** التنبيهات توجه المدير دائماً إلى صفحات الإدارة والمراجعة.
- **تطبيق المستخدم (App):** التنبيهات توجه المستخدم إلى صفحة الفكرة أو الملف الشخصي المعني.
